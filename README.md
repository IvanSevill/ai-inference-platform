# AI Inference Platform

A distributed AI infrastructure laboratory focused on Docker, Docker Compose,
CI/CD, observability and Kubernetes.

The goal is not to build a complex application. The goal is to understand how
containerized services are built, connected, persisted, monitored, scaled and
orchestrated.

## Status

🚧 Initial architecture and Docker fundamentals.
