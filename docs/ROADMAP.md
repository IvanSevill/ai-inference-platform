# Roadmap

## Phase 1 — Docker fundamentals

- [ ] Create the first minimal service
- [ ] Build its Docker image
- [ ] Run it as a container
- [ ] Add a second service
- [ ] Connect services through a Docker network
- [ ] Add persistent storage where appropriate
- [ ] Add environment-based configuration
- [ ] Add health checks

## Phase 2 — Docker Compose

- [ ] Move the local stack to `compose.yaml`
- [ ] Define explicit networks
- [ ] Define volumes
- [ ] Test service discovery
- [ ] Test multiple worker replicas

## Phase 3 — CI

- [ ] Add GitHub Actions workflow
- [ ] Validate Docker builds
- [ ] Validate Compose configuration
- [ ] Run basic tests
- [ ] Publish images to GHCR

## Phase 4 — AI platform

- [ ] Add inference service
- [ ] Add embeddings
- [ ] Add queue
- [ ] Add vector database
- [ ] Add object storage
- [ ] Add Prometheus
- [ ] Add Grafana

## Phase 5 — Kubernetes

- [ ] Create local multi-node cluster
- [ ] Migrate stateless services
- [ ] Add Kubernetes Services
- [ ] Add configuration and secrets
- [ ] Add persistent storage
- [ ] Add Ingress
- [ ] Add probes

## Phase 6 — Scaling and resilience

- [ ] Test self-healing
- [ ] Test multiple replicas
- [ ] Add Horizontal Pod Autoscaler
- [ ] Generate artificial load
- [ ] Observe scale-out and scale-in
- [ ] Test rolling updates
- [ ] Simulate failures

## Phase 7 — CD

- [ ] Deploy registry images to Kubernetes
- [ ] Automate deployment from CI/CD
- [ ] Test rolling delivery
